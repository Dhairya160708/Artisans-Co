Every piece we release carries a number — 04/50, 11/30, 01/12 — printed
quietly on its accompanying card. It is not a marketing device. It is a
fact about how the piece was made.

## Small workshops, small runs

None of the artisans we work with operate at industrial scale. A block
print run of thirty lengths, or a set of twelve painted folios, represents
real weeks of hand labour. Numbering the edition is simply an honest
account of how many exist.

## What it changes for you

When a piece sells out, it sells out — we don't reorder a "limited" run
that quietly restocks. Once fifty are gone, that drop is closed, and the
next one starts from a different workshop, a different city, a different
technique.
