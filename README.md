# Artisans Co

A drop site for an artisans brand, with a journal section, built with Next.js and TypeScript.

## Tech stack

- Next.js (App Router)
- React
- TypeScript

## Getting started

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Open http://localhost:3000 in your browser.

## Project structure

- `app/` - routes and pages
- `components/` - reusable UI components
- `content/journal/` - journal entries
- `lib/` - shared helpers
- `public/` - static assets

> This is a demo project built for portfolio purposes.
